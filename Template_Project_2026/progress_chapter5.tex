\section{สรุปผลการดำเนินโครงงาน}

โครงงานนี้ได้พัฒนาเว็บแอปพลิเคชันสำหรับปกปิดใบหน้าในภาพและวิดีโอ โดยเชื่อมกระบวนการอัปโหลด ตรวจจับใบหน้า สร้าง Face Map เลือกบุคคลที่จะปกปิด ตรวจสอบตัวอย่าง และส่งออกผลลัพธ์เข้าด้วยกัน ผู้ใช้สามารถเลือกเอฟเฟกต์และใช้ Manual Control กำหนดบริเวณเพิ่มเติมได้ นอกจากนี้ได้เพิ่ม Livestream พร้อมตัวเลือกโมเดล โหมดการปกปิด และการเลือกบุคคลหลายราย

ผลการดำเนินงานในภาคการศึกษานี้คือระบบต้นแบบที่รองรับกระบวนการหลักดังกล่าว และมีตัวเลือกโมเดลกับรูปแบบการปกปิดให้ผู้ใช้ปรับตามการใช้งาน ผลเปรียบเทียบแบบจำลองและตัวเลขอ้างอิงได้รวบรวมไว้ในบทที่ 4 ทั้งนี้ ผลอ้างอิงและผลระดับโมเดลยังไม่ยืนยันความแม่นยำของการจัดกลุ่ม การติดตาม หรือความครอบคลุมของการปกปิดตลอดทั้งระบบ จึงยังต้องเก็บผลการประเมินแบบ end-to-end เพิ่มเติม

งานในภาคการศึกษาถัดไปจะมุ่งเตรียมชุดทดสอบที่มีคำตอบจริง วัดความถูกต้องและเวลาในการประมวลผล วิเคราะห์กรณีตรวจจับหรือจัดกลุ่มผิด และปรับปรุงการจัดการงานเบื้องหลัง ก่อนขยายการตรวจจับไปยังข้อมูลส่วนบุคคลประเภทอื่น รายละเอียดแผนงานแสดงในหัวข้อสิ่งที่จะทำต่อในเทอมหน้า

\section{ข้อจำกัดของระบบ}

\subsection{ข้อจำกัดด้านการทำงาน}

ระบบตรวจจับอัตโนมัติเน้นใบหน้าเป็นหลัก จึงยังไม่ครอบคลุมป้ายทะเบียน ข้อความ ลายเซ็น หรือข้อมูลส่วนบุคคลประเภทอื่นโดยอัตโนมัติ ผู้ใช้ต้องวาดกรอบ Manual Blur เพื่อปกปิดข้อมูลเพิ่มเติม ความต่อเนื่องของการจัดกลุ่มบุคคลและการติดตามกรอบอาจลดลงเมื่อภาพเบลอมาก วัตถุเคลื่อนที่เร็ว ถูกบดบัง หรือมีมุมหน้าเปลี่ยนแปลงมาก

สถานะของงานเบื้องหลังถูกเก็บไว้ในหน่วยความจำ จึงไม่เหมาะกับการทำงานหลาย instance หรือการรีสตาร์ตเซิร์ฟเวอร์ นอกจากนี้ backend จะกำหนดตัวแปรขนาดไฟล์สูงสุดไว้ แต่ยังไม่ได้ใช้บังคับก่อนบันทึกไฟล์ และในปัจจุบันยังไม่มีกระบวนการลบไฟล์อัปโหลดตามเวลา

\section{ปัญหา อุปสรรค และแนวทางแก้ไข}

\subsection{การวิเคราะห์ความเสี่ยงของข้อผิดพลาดจากกระบวนการทำงาน}

การวิเคราะห์ต่อไปนี้อาศัยขั้นตอนและเงื่อนไขในซอร์สโค้ด เพื่อระบุกรณีที่ควรตรวจสอบ ยังไม่ใช่ผลทดลองหรือหลักฐานว่าปัญหาเกิดขึ้นด้วยความถี่เท่าใด การยืนยันแต่ละกรณีต้องมีภาพหรือคลิปพร้อมคำตอบจริงสำหรับเปรียบเทียบ

  \item \textbf{ตรวจจับผิดหรือตรวจไม่พบ:} แสงน้อย ย้อนแสง มุมหน้า การบดบัง และใบหน้าขนาดเล็กอาจทำให้กรอบหรือ confidence เปลี่ยนไป นอกจากข้อผิดพลาดของโมเดล pipeline ยังมีเงื่อนไขตัดกรอบที่เล็กกว่า 32 พิกเซลหรือ confidence ต่ำกว่า 0.30 ก่อนจัดกลุ่ม จึงควรแยกกรณีโมเดลไม่ตรวจพบออกจากกรณีตรวจพบแต่ไม่ผ่านเงื่อนไขขั้นถัดไป
  \item \textbf{จัดกลุ่มบุคคลผิด:} ภาพตัดใบหน้าที่มีบุคคลอื่นติดอยู่ มุมหน้าที่เปลี่ยน หรือการสร้าง embedding ไม่สำเร็จอาจทำให้ตัวแทนใบหน้าไม่เหมาะกับการจับคู่ ค่าเกณฑ์ที่ผ่อนปรนเกินไปเสี่ยงรวมคนละคน ส่วนค่าเกณฑ์ที่เข้มเกินไปเสี่ยงแยกคนเดียวเป็นหลายกลุ่ม ควรตรวจทั้งสองกรณีและความครอบคลุมของคีย์เฟรมก่อนปรับค่าเกณฑ์
  \item \textbf{กรอบติดตามคลาดเคลื่อน:} เฟรมที่ข้ามการตรวจจับใช้ตำแหน่งประมาณจากความเร็วเดิม หากบุคคลเปลี่ยนทิศทางเร็ว เดินสวนกัน หรือถูกบัง การจับคู่จาก IoU อาจไม่ต่อเนื่องหรือสลับกรอบ ควรตรวจตำแหน่งและรหัสบุคคลก่อน ระหว่าง และหลังเหตุการณ์ รวมถึงผลของช่วงห่างระหว่างเฟรมตรวจจับ
  \item \textbf{ผลปกปิดไม่ตรงตามที่เลือก:} การจัดกลุ่มหรือการติดตามผิดส่งผลให้กรอบปกปิดอาจตกหล่นหรือถูกนำไปใช้กับคนอื่น การตรวจตัวอย่างก่อนส่งออกและ Manual Control ช่วยให้ผู้ใช้ปรับพื้นที่ได้ แต่ยังต้องตรวจวิดีโอผลลัพธ์ตลอดช่วงที่มีความเสี่ยง ไม่ใช้ภาพตัวอย่างเพียงเฟรมเดียวเป็นหลักฐานว่าปกปิดครบทั้งคลิป
\end{enumerate}

เมื่อดำเนินการทดสอบจะบันทึกชื่อสื่อ หมายเลขเฟรม สภาพแสง มุมหน้า การบดบัง การเคลื่อนไหว กรอบจริง กรอบที่ระบบให้ และรหัสบุคคล พร้อมจัดประเภทข้อผิดพลาดและระบุผลกระทบต่อการปกปิด เพื่อเชื่อมผลวิเคราะห์กับแนวทางแก้ไขอย่างตรวจสอบได้

\section{สิ่งที่จะทำต่อในเทอมหน้า}

\subsection{การปรับปรุงฟังก์ชันการทำงาน}

ควรเพิ่มแบบจำลองตรวจจับป้ายทะเบียนและโมดูล OCR/PII เพื่อลดการวาดกรอบด้วยตนเอง เพิ่มหน้าสำหรับแก้ไขผลการจัดกลุ่มบุคคล และอนุญาตให้กำหนดกรอบเริ่มต้นได้มากกว่าหนึ่งจุดในวิดีโอ นอกจากนี้ควรเพิ่มระบบลบไฟล์ชั่วคราว กำหนดขนาดไฟล์และสิทธิ์เข้าถึงให้ชัดเจน และปรับปรุงคุณภาพการตรวจจับและติดตามวัตถุหรือใบหน้าทั้งในด้านความเร็วและความแม่นยำเพิ่มเติม

\subsection{แนวทางการวิจัยต่อยอด}

จัดเตรียมชุดทดสอบที่มีสภาพแสง มุมหน้า การเคลื่อนไหว ความละเอียด และจำนวนบุคคลต่างกัน แล้ววัด precision, recall, identity consistency, blur coverage และเวลาเฉลี่ยต่อเฟรม นอกจากนี้ทดสอบว่าระดับการเบลอแต่ละแบบเพียงพอต่อการลดความสามารถในการระบุตัวบุคคลหรือไม่ และประเมินประสบการณ์ผู้ใช้ด้วยแบบสอบถามหลังใช้งาน
