## สไลด์ 2: การเผยแพร่ภาพอาจเปิดเผยตัวตนโดยไม่ตั้งใจ

- ภาพและวิดีโอถูกเผยแพร่ผ่านสื่อสังคมออนไลน์ ระบบกล้องวงจรปิด และบริการคลาวด์
- ใบหน้าเป็นข้อมูลชีวมิติที่สามารถเชื่อมโยงกลับไปยังตัวบุคคล
- การปกปิดด้วยมือใช้เวลามาก โดยเฉพาะวิดีโอที่มีหลายคนหรือหลายเฟรม
- การเบลอทั้งภาพทำให้สูญเสียรายละเอียดสำคัญของสื่อ

แนวทางของโครงงาน: ตรวจจับและปกปิดเฉพาะบุคคลหรือพื้นที่ที่ต้องการ

ภาพประกอบแนะนำ: ภาพเดียวกันก่อนปกปิดและหลังปกปิดเฉพาะใบหน้า

---

## สไลด์ 3: วัตถุประสงค์ของโครงงาน

1. พัฒนาเว็บแอปพลิเคชันสำหรับปกปิดใบหน้าในภาพและวิดีโอ
2. ตรวจจับและจัดกลุ่มใบหน้าของบุคคลเดียวกัน เพื่อเลือกปกปิดรายบุคคล
3. รองรับการวาดกรอบปกปิดด้วยตนเองและการติดตามวัตถุ
4. เลือกรูปแบบการปกปิด ตรวจสอบตัวอย่าง และส่งออกผลลัพธ์
5. จัดทำแนวทางประเมินความแม่นยำ ความครอบคลุม และความเร็ว

## สไลด์ 4: ขอบเขตของระบบปัจจุบัน

### ไฟล์ที่รองรับ

- ภาพ: JPG, JPEG, PNG และ WEBP
- วิดีโอ: MP4, MOV, AVI, MKV และ WEBM

### ความสามารถหลัก

- ตรวจจับและปกปิดใบหน้าอัตโนมัติ
- เลือกบุคคลที่ต้องการเบลอผ่าน Face Map
- ปกปิดข้อมูลอื่นด้วย Manual Control
- เลือก Gaussian Blur, Pixelation หรือ Black Box

### ข้อจำกัด

- ป้ายทะเบียนและข้อความยังไม่ถูกตรวจจับอัตโนมัติ
- ประสิทธิภาพขึ้นกับคุณภาพวิดีโอ สภาพแสง และทรัพยากรเครื่อง

## สไลด์ 5: กระบวนการทำงานตั้งแต่อัปโหลดจนถึงส่งออก

1. อัปโหลดภาพหรือวิดีโอ
2. สร้างข้อมูลสื่อและเฟรมตัวอย่าง
3. ตรวจจับใบหน้าและจัดกลุ่มบุคคล
4. เลือกบุคคลที่จะปกปิด หรือวาดกรอบด้วยตนเอง
5. กำหนดรูปแบบและระดับการปกปิด
6. ตรวจสอบตัวอย่างและส่งออกผลลัพธ์

ข้อความประกอบ: ผู้ใช้สามารถตรวจสอบและปรับผลก่อนนำสื่อไปเผยแพร่

ภาพประกอบแนะนำ: Flow แนวนอน 6 ขั้น พร้อมภาพหน้าจอจริงประกอบ

## สไลด์ 6: สถาปัตยกรรมและเทคโนโลยีที่ใช้จริง

### Frontend

- Next.js 16, React 19 และ TypeScript
- Tailwind CSS สำหรับส่วนติดต่อผู้ใช้
- React Dropzone และ React Konva สำหรับอัปโหลดและวาดกรอบ

### Backend

- FastAPI และ Python
- SQLAlchemy และ SQLite สำหรับจัดเก็บข้อมูลระบบ
- Cloudinary สำหรับจัดเก็บผลลัพธ์ เมื่อมีการตั้งค่าที่จำเป็น

### AI และ Image Processing

- YOLO: ตรวจจับตำแหน่งใบหน้า
- InsightFace / ArcFace: สร้างเวกเตอร์ลักษณะใบหน้า
- OpenCV: ประมวลผลภาพ วิดีโอ และกรอบปกปิด

ข้อความสั้นแสดงสถาปัตยกรรม:

ผู้ใช้ -> Next.js / React -> FastAPI -> AI Services -> SQLite / Cloudinary

## สไลด์ 7: การตรวจจับและติดตามบุคคลในวิดีโอ

### 1. Face Detection

YOLO ค้นหาตำแหน่งใบหน้าในแต่ละเฟรม

### 2. Face Recognition

InsightFace / ArcFace สร้าง Face Embedding เพื่อเปรียบเทียบความคล้ายของใบหน้า

### 3. Identity Grouping

รวมใบหน้าของบุคคลเดียวกันเป็นรายการเดียวใน Face Map

### 4. Tracking

IoU และ Hungarian Algorithm ช่วยจับคู่กรอบใบหน้าระหว่างเฟรม

### 5. Manual Object Tracking

OpenCV KCF / CSRT ใช้ติดตามกรอบที่ผู้ใช้กำหนดเอง

ข้อความสรุป: ลดการเลือกใบหน้าซ้ำทุกเฟรม และช่วยควบคุมการปกปิดเป็นรายบุคคล

## สไลด์ 15: ตัวชี้วัดที่ใช้ประเมินระบบในขั้นถัดไป

### Face Detection

- Precision: สัดส่วนกรอบใบหน้าที่ตรวจพบถูกต้อง
- Recall: สัดส่วนใบหน้าจริงที่ระบบตรวจพบ

### Identity and Tracking

- Identity consistency: ความต่อเนื่องของการจัดกลุ่มบุคคล
- Tracking stability: ความเสถียรของกรอบข้ามเฟรม

### Privacy and Performance

- Blur coverage: สัดส่วนใบหน้าหรือพื้นที่เป้าหมายที่ถูกปกปิด
- Processing time: เวลาเฉลี่ยต่อภาพ เฟรม หรือวิดีโอ

สถานะปัจจุบัน: กำหนดตัวชี้วัดแล้ว และอยู่ระหว่างจัดเตรียมชุดทดสอบสำหรับเก็บผลจริง

## ข้อมูลในสไลด์เดิมที่ต้องแก้ให้ตรงกับระบบจริง

- เปลี่ยน `PostgreSQL` เป็น `SQLite`
- เปลี่ยน `Prisma` เป็น `SQLAlchemy`
- ระบุ `InsightFace / ArcFace` เป็นกลไกหลักสำหรับ Face Embedding
- ไม่ระบุ `RetinaFace` และ `MTCNN` ว่าเป็นส่วนหลักของระบบ หากยังไม่ได้ใช้งานจริง
- ไม่ระบุว่าระบบตรวจจับป้ายทะเบียนอัตโนมัติ เพราะปัจจุบันยังใช้ Manual Control
- ไม่ใส่ `YOLOv8-LPR` หรือ `YOLOv8 + CRAFT` ในหมวดความสามารถที่ทำเสร็จแล้ว
- ไม่ใช้ค่า `25.2 ms/frame` เว้นแต่มีผลทดสอบของระบบปัจจุบันพร้อมสภาพแวดล้อมที่ตรวจสอบได้
- ไม่แสดงกราฟจากแหล่งภายนอกเป็นผลทดสอบของโครงงาน
- ไม่ระบุ `Celery / Redis` เป็นเทคโนโลยีที่ใช้งานแล้ว เพราะยังเป็นแนวทางพัฒนาต่อ
- ไม่ระบุว่าบังคับขนาดไฟล์สูงสุด 500 MB แล้ว เพราะซอร์สโค้ดมีค่ากำหนดไว้แต่ยังไม่ได้ตรวจบังคับก่อนบันทึก
